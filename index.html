About Farees Azuan

I am a Senior Technical Engineer (Network Engineer) based in Malaysia, focused on secure connectivity for small and mid-sized businesses. My experience covers Fortigate firewalls, Omada SDN, Cisco switching, QNAP storage, EdgeCore, CCTV solutions, and Microsoft server products.

I have delivered projects such as large-scale branch VPN rollouts, Wi‑Fi redesigns with guest access, and technical guidance on modern identity and access solutions like Keycloak.

Certifications: CCNA (valid to 2028), CCNP Security (valid to 2028), Fortinet NSE3 Secure Networking, previously CompTIA A+.

The goal of this site is to showcase what I can deliver and to provide a reference point for colleagues, management, and potential customers.

Highlighted Projects

Omada VPN Rollout to 45 Branches

Role: Network Engineer / Senior Technical Engineer

Technologies: Omada VPN routers (45 outlets), Fortigate 200‑F firewall at HQ, VPN, Microsoft server environment.

Designed and implemented secure connectivity between HQ and 45 retail outlets. Installed and configured Omada VPN routers, deployed a Fortigate 200‑F at HQ, and created IPsec VPN policies to connect all branches.

Result: centralized, secure access to HQ resources for all shops, with easier management and troubleshooting for the operations team.

Corporate Wi‑Fi Redesign with Guest Voucher Access

Role: Network Engineer

Technologies: Ruijie RG‑105GW‑X access points, Wi‑Fi voucher system, user training.

Redesigned an office Wi‑Fi environment to support guest/visitor access via voucher codes. Planned the migration, replaced legacy APs with Ruijie devices, and configured the voucher solution.

Provided training to staff on how to generate vouchers from the management application, improving security and control over guest access.

Keycloak SSO & Risk Analysis (Ongoing)

Role: Technical Specialist / Mentor

Technologies: Keycloak, SSO, risk-based login analysis, security analytics.

Supporting a thesis project to implement Keycloak single sign-on for internal applications and to analyse login risk in real time. Advising on architecture, configuration, and security best practices.

Objective: create a standards-based SSO solution with risk scoring that can later be applied to real-world customer environments.
